Introduce

Over 4 years as a game server and backend developer, I've built hands-on experience that spans far beyond maintenance and new features — covering performance optimization, operational infrastructure, and real-time server design. Directly responsible for live services running simultaneously across Korea, Japan, Taiwan, and English-speaking regions, I've tracked down and resolved issues that cut straight to the heart of stability and performance: eliminating login bottlenecks, migrating ranking systems to Redis, building a chat server from the ground up, stabilizing payments, and executing DB migrations.

I find meaning in that invisible work: where silence is the only sign that anything was done at all.
